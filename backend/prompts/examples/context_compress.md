# 示例：短对话压缩成 9 字段

## 输入

旧摘要：空。

新增对话：

```json
[
  {"role":"user","content":"下周末想去杭州玩两天，两个人，喜欢老街区，别太赶"},
  {"role":"assistant","content":"好的，我先按两天轻松节奏排一版，西湖和河坊街一带可以吗？"},
  {"role":"user","content":"可以，但灵隐寺一定要去，预算两个人 2000 以内"},
  {"role":"tool","content":"search_places 返回 6 个杭州候选，包含灵隐寺、河坊街、南宋御街"},
  {"role":"assistant","content":"记下了，灵隐寺放第一天上午，预算按两人 2000 控制。"},
  {"role":"user","content":"第二天别排博物馆，想多走走"}
]
```

## 说明

- 三条用户消息逐字保留、顺序不变，没有合并成一句。
- 助手说的「记下了」没有写进事实字段，只记录用户确实说过的内容。
- 没有出现的 trip_id、version 不编造，直接写明「未保存」。
